# Correspondencia de pseudo-instrucciones RISC-V

| Pseudo-instrucción     | Instrucciones reales                                                 | Descripción                                                                                            | Ejemplo de uso                                                                               | Origen |
| :--------------------- | :------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------- | :----- |
| mv rd, rs1             | addi rd, rs1, 0                                                      | Copia el contenido de un registro a otro registro utilizando una suma con el inmediato 0.              | mv a2, a1. En el ejercicio de producto escalar para pasar argumentos.                        | [1]    |
| li rd, constante       | addi rd, x0, constante si es de 12 bits; lui + addi si es de 32 bits | Carga un valor inmediato en un registro de destino.                                                    | li a7, 10. Utilizado al final de los bucles para cargar el código de salida de sistema.      | [1]    |
| la rd, etiqueta        | auipc + addi                                                         | Carga la dirección de una etiqueta, referencia simbólica a memoria, en un registro.                    | la t2, datos. En el ejercicio 1 para cargar la dirección base de un vector.                  | [1]    |
| nop                    | addi x0, x0, 0                                                       | No realiza ninguna operación; el procesador no cambia su estado.                                       | nop. Insertada por el ensamblador o hardware para resolver riesgos de datos en segmentación. | [1, 2] |
| neg rd, rs2            | sub rd, x0, rs2                                                      | Realiza la negación aritmética, cambio de signo, de un valor.                                          | neg t1, t2. Implementación de complemento a dos en ejercicios de registros.                  | [1]    |
| not rd, rs1            | xori rd, rs1, -1                                                     | Realiza la negación lógica bit a bit.                                                                  | not t1, t2. Operación lógica en ejercicios de manipulación de bits.                          | [1]    |
| beqz rs1, etiqueta     | beq rs1, x0, etiqueta                                                | Salta a la etiqueta especificada si el contenido del registro es igual a cero.                         | beqz a1, error. En el simulador para controlar flujos de error en bucles.                    | [1]    |
| bnez rs1, etiqueta     | bne rs1, x0, etiqueta                                                | Salta a la etiqueta si el contenido del registro es distinto de cero.                                  | bnez x5, 100. Control de salida de bucles condicionales.                                     | [1]    |
| bgt rs1, rs2, etiqueta | blt rs2, rs1, etiqueta                                               | Salta si el primer registro es mayor que el segundo, invirtiendo los operandos en la instrucción real. | bgt t2, t3, continua. En el ejercicio 2 para implementar estructuras IF, a <= b.             | [1]    |
| ble rs1, rs2, etiqueta | bge rs2, rs1, etiqueta                                               | Salta si el primer registro es menor o igual que el segundo.                                           | ble x5, x6, 100. Utilizado para implementar límites de iteración en bucles.                  | [1]    |
| j etiqueta             | jal x0, etiqueta                                                     | Realiza un salto incondicional a una dirección relativa al PC sin guardar dirección de retorno.        | j bucle. Salto incondicional al inicio del bucle for o while.                                | [1]    |
| ret                    | jalr x0, 0(ra)                                                       | Retorna de una función saltando a la dirección guardada en el registro ra.                             | ret. Utilizado en la función suma o factorial para volver al main.                           | [1]    |
| call etiqueta          | auipc + jalr                                                         | Llamada a función que guarda la dirección de retorno en ra.                                            | call func. Utilizado en ejercicios de funciones para invocar subrutinas.                     | [1]    |
| mv rd, rs1             | addi rd, rs1, 0                                                      | Copia el contenido de un registro en otro.                                                             | mv a0, a5                                                                                    | [3]    |
| li rd, inm             | addi rd, x0, inm                                                     | Carga un valor inmediato en un registro.                                                               | li a7, 10                                                                                    | [3, 4] |
| la rd, label           | auipc + addi                                                         | Carga la dirección de una etiqueta en un registro.                                                     | la a1, x                                                                                     | [3, 4] |
| nop                    | addi x0, x0, 0                                                       | No realiza ninguna operación.                                                                          | nop                                                                                          | [3, 5] |
| neg rd, rs1            | sub rd, x0, rs1                                                      | Realiza la negación aritmética, valor negativo.                                                        | neg x5, x6                                                                                   | [3]    |
| not rd, rs1            | xori rd, rs1, -1                                                     | Realiza la negación lógica bit a bit.                                                                  | not x5, x6                                                                                   | [3]    |
| seqz rd, rs1           | sltiu rd, rs1, 1                                                     | Pone el destino a 1 si el registro fuente es cero.                                                     | seqz x5, x6                                                                                  | [3]    |
| snez rd, rs1           | sltu rd, x0, rs1                                                     | Pone el destino a 1 si el registro fuente es distinto de cero.                                         | snez x5, x6                                                                                  | [3]    |
| beqz rs1, offset       | beq rs1, x0, offset                                                  | Salta si el registro es igual a cero.                                                                  | beqz a2, FIN                                                                                 | [3, 4] |
| bnez rs1, offset       | bne rs1, x0, offset                                                  | Salta si el registro es distinto de cero.                                                              | bnez t3, POS                                                                                 | [3, 6] |
| j offset               | jal x0, offset                                                       | Realiza un salto incondicional.                                                                        | j cont                                                                                       | [3, 4] |
| ret                    | jalr x0, ra, 0                                                       | Retorno de una función, salta a la dirección en ra.                                                    | ret                                                                                          | [3, 7] |
| call label             | auipc + jalr                                                         | Llamada a una función estableciendo la dirección de retorno en ra.                                     | call func                                                                                    | [3]    |
